# Feature Completion Scorecard

Bewertung pro Funktion: 0 bis 100 Punkte.

## Pflichtpunkte

| Kategorie | Punkte |
|---|---:|
| Modelllogik korrekt | 20 |
| UI wirklich verbunden | 10 |
| Measurement/Units korrekt | 10 |
| Undo/Redo | 10 |
| Save/Load/Project state | 10 |
| Tests | 15 |
| SketchUp-Verhaltensvergleich | 10 |
| Docs/Changelog | 5 |
| Error handling/fail closed | 5 |
| Rollback/Versionierung | 5 |

## Status

- 90–100: ready
- 70–89: experimental
- 0–69: planned oder nicht mergen

Eine Funktion unter 90 darf nicht als vollständig beworben werden.
