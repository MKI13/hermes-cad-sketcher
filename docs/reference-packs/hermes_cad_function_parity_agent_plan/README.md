# Hermes CAD Function Parity Agent Plan

Erstellt am: 2026-06-06

Ziel dieses Pakets: Hermes Agent soll das Repository `MKI13/hermes-cad-sketcher` sauber weiterentwickeln, so dass bestehende und geplante Funktionen nicht nur als Deko in der Oberfläche erscheinen, sondern vollständig, testbar, versioniert und SketchUp-ähnlich funktionieren — ohne SketchUp-/Trimble-Icons, Logos, Texte, geschützte Layouts oder fremde Code-Assets zu kopieren.

Dieses Paket ist für Hermes Agent gedacht. Es enthält:
- Master-Prompt
- aktueller Repository-Befund
- Funktions-Paritätsplan zu SketchUp-ähnlichem Verhalten
- UI/UX-Regeln
- verständliche eigene Icon-Liste
- GitHub-Versionierungs- und Push-Workflow
- Definition of Done
- QA-/Test-Matrix
- Issue-Vorlagen
- Agent-Konfiguration
- Quellenprotokoll-Vorlage

Kurzregel:
**Jede Funktion braucht Modelllogik, UI, Tests, Dokumentation, SketchUp-Verhaltensvergleich, Rollback-Notiz und Versionierung. Keine Deko-Funktionen.**
