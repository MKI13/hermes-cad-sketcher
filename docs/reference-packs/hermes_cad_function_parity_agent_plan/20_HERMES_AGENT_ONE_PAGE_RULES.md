# Hermes Agent — Ein-Seiten-Regeln

1. Keine Deko-Funktionen.
2. Kein SketchUp-/Trimble-Icon, Logo, Screenshot, Text oder Code kopieren.
3. Jede Funktion: erst Issue lesen, dann Quelle recherchieren, dann TDD.
4. Millimeter bleiben Basiseinheit.
5. UI folgt Modelllogik, nicht andersrum.
6. Komponenten brauchen Definition + Instanz + Make Unique.
7. Gruppen/Komponenten brauchen aktiven Bearbeitungskontext.
8. Push/Pull arbeitet auf Faces, mit Preview und Measurement Box.
9. Measurement Box ist aktives Eingabesystem, nicht nur Anzeige.
10. Outliner/Tags/Materials müssen echten Modellzustand steuern.
11. Import/Export nur behaupten, was getestet ist.
12. Rendering separat vom CAD-Kern.
13. `npm run check` vor jedem Commit.
14. Branch pro Issue.
15. Conventional Commit.
16. Changelog/README/AGENTS aktualisieren.
17. Proof Bundle ins Issue/PR.
18. Rollback-Notiz.
19. Kein direkter Push auf main.
20. Bei Risiko stoppen und Marios fragen.
