# Issue: Interner Render Workspace im rechten Hermes Tray

## Ziel

Ein Render-Panel im bestehenden Hermes CAD Fenster ergänzen.

## Aufgaben

- Panel `Render` im rechten Tray ergänzen.
- Qualität wählen: Draft / Preview / Final.
- Kamera aus aktueller View speichern.
- Licht-Preset wählen.
- Materialauswahl für aktuelle Selektion.
- Vorschau starten.
- Keine SketchUp Icons.

## Acceptance Criteria

- Panel blockiert Viewport nicht.
- Funktionen sind sichtbar, aber nicht überladen.
- Auswahlbasiertes Materialsetzen funktioniert.
- Kamera-Preset kann gespeichert werden.
- `npm run check` grün.
