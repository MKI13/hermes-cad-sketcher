# Texturen, Assets und Lizenzregeln

## Grundregel

Realistisches Rendering braucht Texturen, aber Texturen sind oft urheberrechtlich geschützt. Hermes darf keine fremden Texturen, Icons oder Modelle kopieren.

## Erlaubt

- Eigene Fotos/Texturen von Marios/EF-Sinn.
- CC0/Public-Domain Texturen, wenn Quelle dokumentiert ist.
- Gekaufte/ lizenzierte Assets, wenn Lizenz bei Projekt dokumentiert ist.
- Procedural Materials, die Hermes selbst erzeugt.

## Nicht erlaubt

- SketchUp Icons oder Trimble Assets.
- Hersteller-Texturen ohne Lizenz.
- YouTube-/Google-Bilder einfach herunterladen und einbauen.
- GitHub-Assets ohne Lizenzprüfung.

```yaml
  - customer-image

  - resale-as-asset-pack
```
