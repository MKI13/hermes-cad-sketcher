# Ziel

Hermes CAD soll parametrische Schrank- und Korpus-Komponenten für Schreiner erstellen.

## Anforderungen

- [ ] Korpus Breite/Höhe/Tiefe.
- [ ] Seiten/Boden/Deckel/Rückwand.
- [ ] Materialstärke.
- [ ] Türen.
- [ ] Schubladen.
- [ ] Einlegeböden.
- [ ] Sockel/Füße.
- [ ] Griffe/Beschläge.
- [ ] Kantenband-Metadaten.
- [ ] BOM/Zuschnitt-Metadaten.
- [ ] Presets: Unterschrank, Hängeschrank, Hochschrank, Kleiderschrank, Schubladenschrank.
- [ ] Dynamic Options UI.
- [ ] Make Unique und Component Library kompatibel.

## Recherchepflicht

- [ ] SketchUp Dynamic Components für Cabinets.
- [ ] YouTube Cabinet Dynamic Component Workflows.
- [ ] GitHub Cabinet/Cutlist/Open Source Projekte.
- [ ] OpenCutList-artige Workflows analysieren, aber nicht kopieren.

## Abnahme

- [ ] Mindestens 5 Schranktypen funktionieren.
- [ ] Materialstärke bleibt beim Skalieren konstant.
- [ ] BOM-Metadaten korrekt.
