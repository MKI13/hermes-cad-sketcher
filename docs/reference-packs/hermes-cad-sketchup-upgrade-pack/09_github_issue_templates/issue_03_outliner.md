# Ziel

Hermes CAD braucht einen Outliner wie ein Strukturbaum für Modellorganisation.

## Anforderungen

- [ ] Gruppen anzeigen.
- [ ] Komponenten anzeigen.
- [ ] Verschachtelung anzeigen.
- [ ] Expand/Collapse.
- [ ] Suche.
- [ ] Rename.
- [ ] Drag & Drop.
- [ ] Sichtbarkeit toggeln.
- [ ] Lock toggeln.
- [ ] Auswahl-Sync Viewport ↔ Outliner.
- [ ] Kontextmenü.
- [ ] Performance bei 10.000 Nodes.

## Recherchepflicht

- [ ] Offizielle Outliner/Hierarchy Dokumentation prüfen.
- [ ] Videos zum Outliner-Workflow.
- [ ] Forum-Probleme und Nutzererwartungen prüfen.

## Abnahme

- [ ] Nutzer kann große Modelle organisieren.
- [ ] Select/Hide/Lock/Rename funktionieren.
- [ ] Undo/Redo bei Strukturänderungen.
