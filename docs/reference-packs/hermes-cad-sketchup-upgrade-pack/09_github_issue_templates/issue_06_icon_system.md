# Ziel

Hermes CAD braucht eigene Icons und darf keine SketchUp Icons übernehmen.

## Anforderungen

- [ ] Icon Guidelines.
- [ ] SVG Icon Pipeline.
- [ ] Light/Dark Mode.
- [ ] Toolbar Icons.
- [ ] Panel Icons.
- [ ] Active/Hover/Disabled States.
- [ ] Asset License Dokumentation.
- [ ] Prüfung auf keine Markenverwechslung.

## Verbote

- [ ] Keine SketchUp Icons.
- [ ] Keine nachgezeichneten SketchUp Icons.
- [ ] Keine SketchUp Screenshots.
- [ ] Keine unklar lizenzierten Icons.

## Abnahme

- [ ] Alle Icons unter `assets/icons/hermes/`.
- [ ] Alle Quellen in `docs/design/asset_licenses.md`.
- [ ] Eigenständige Hermes-CAD-Optik.
